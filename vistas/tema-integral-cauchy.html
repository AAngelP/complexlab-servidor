Teorema y Fórmula Integral de Cauchy

Conocimientos Previos
  • Dominio simplemente conexo (región sin "agujeros").
  • Contorno cerrado simple C orientado positivamente (sentido antihorario).
  • Identificación de puntos singulares dentro y fuera de un contorno cerrado.

1. Teorema de Cauchy-Goursat: Si una función f(z) es analítica en todos los puntos interiores y sobre un contorno cerrado simple C, entonces:

∮C f(z)dz = 0

2. Fórmula Integral de Cauchy: Si f(z) es analítica dentro y sobre un contorno cerrado simple C (antihorario) y z0 es cualquier punto interior a C, entonces:

∮C f(z)z−z0dz = 2πif(z0)

3. Generalización para Derivadas de Orden Superior: Bajo las mismas hipótesis, f posee derivadas de todos los órdenes en z0 dadas por:

∮C f(z)(z−z0)n+1dz = 2πin! f(n)(z0)

Casos de Estudio Interactivos

Caso 1: Aplicación Directa de Cauchy-Goursat (Integral = 0) ▾

Evaluar ∮C [ez / (z − 4)] dz donde C es la circunferencia |z| = 2:

Análisis de singularidades: El denominador se anula en z = 4. Como |4| = 4 > 2, la singularidad está fuera del contorno C.

∮|z|=2 ezz−4dz = 0

Al ser analítica en todo el interior y frontera de |z| = 2, el Teorema de Cauchy-Goursat garantiza que la integral vale 0.

Caso 2: Fórmula Integral de Cauchy Simple (n = 0) ▾

Evaluar ∮C [cos(πz) / (z − 1)] dz donde C es el círculo |z| = 2 (antihorario):

Identificación: f(z) = cos(πz) es entera y z0 = 1 está dentro de |z| = 2 (ya que |1| < 2).

∮|z|=2 cos(πz)z−1dz = 2πi⋅f(1) = 2πicos(π) = 2πi(−1) = −2πi
Caso 3: Fórmula de Cauchy para Derivadas (n = 2) ▾

Evaluar ∮C [e2z / (z + i)3] dz donde C es |z| = 3:

Identificación: Tenemos (z − (−i))2+1, por lo que n = 2, z0 = −i (interior a |z| = 3) y f(z) = e2z.

Calculamos la segunda derivada: f'(z) = 2e2z ⇒ f''(z) = 4e2z.

∮|z|=3 e2z(z+i)3dz = 2πi2! f''(−i) = πi(4e−2i) = 4πie−2i
Caso 4: Factorización del Denominador con una Sola Raíz Interior ▾

Evaluar ∮C [z / (z2 − 9)] dz donde C es la circunferencia |z − 3| = 1:

Factorizamos z2 − 9 = (z − 3)(z + 3). Dentro del disco |z − 3| < 1 solo está z0 = 3, mientras que z = −3 queda fuera. Re agrupamos f(z) = z / (z + 3):

∮C z/(z+3)z−3dz = 2πif(3) = 2πi(33+3) = 2πi(12) = πi
