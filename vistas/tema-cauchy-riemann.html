Cauchy-Riemann, Analiticidad y Laplace

Descomposición Real e Imaginaria
  • Toda función compleja se escribe como f(z) = f(x + iy) = u(x, y) + i v(x, y).
  • Requiere manejo de derivadas parciales de primer y segundo orden (ux, uy, uxx, uyy).

1. Ecuaciones de Cauchy-Riemann (CR): Si f(z) = u(x, y) + iv(x, y) es derivable en z0 = (x0, y0), entonces existen las derivadas parciales y satisfacen:

∂u∂x = ∂v∂y y ∂u∂y = − ∂v∂x

Además, si las parciales son continuas en una vecindad de z0, f es analítica en z0 y su derivada se calcula directamente como:

f'(z) = ux+ivx = vy−iuy

2. Funciones Armónicas y Ecuación de Laplace: Si f = u + iv es analítica en un dominio D, entonces tanto u como v son funciones armónicas en D, es decir, satisfacen la ecuación diferencial de Laplace:

∇2u = ∂2u∂x2 + ∂2u∂y2 = 0 y ∇2v = ∂2v∂x2 + ∂2v∂y2 = 0

Casos de Estudio Interactivos

Caso 1: Comprobar Analiticidad de f(z) = z3 ▾

Expandimos f(x + iy) = (x + iy)3 = (x3 − 3xy2) + i(3x2y − y3). Identificamos:

u(x, y) = x3 − 3xy2   y   v(x, y) = 3x2y − y3

ux=3x2−3y2, vy=3x2−3y2 ⇒ ux=vy✓ uy=−6xy, vx=6xy ⇒ uy=−vx✓

Como las parciales son polinomios (continuas en todo ℝ2), f(z) = z3 es analítica en todo ℂ (función entera) y f'(z) = ux + ivx = 3(x2 − y2 + 2ixy) = 3z2.

Caso 2: Función que NO cumple Cauchy-Riemann f(z) = x2 + iy2 ▾

Tenemos u(x, y) = x2 y v(x, y) = y2. Calculamos las derivadas parciales:

ux=2x, vy=2y ⇒ 2x=2y⇔y=x uy=0, vx=0 ⇒ 0=−0✓

Las ecuaciones de CR solo se cumplen sobre la recta y = x. Como no se cumplen en ningún disco abierto alrededor de ningún punto, f(z) no es analítica en ninguna parte de ℂ (solo es derivable sobre la recta y = x).

Caso 3: Verificar Función Armónica con Laplace ▾

Comprobar si u(x, y) = ex cos y es armónica en todo el plano:

ux=excosy ⇒ uxx=excosy uy=−exseny ⇒ uyy=−excosy ∇2u = uxx+uyy = excosy−excosy = 0

Al cumplirse ∇2u = 0 con segundas parciales continuas, u(x, y) es armónica en todo ℝ2.

Caso 4: Hallar la Armónica Conjugada v(x, y) ▾

Dada u(x, y) = x2 − y2, construir f(z) = u + iv analítica:

Paso 1: Verificamos Laplace: uxx + uyy = 2 + (−2) = 0. Es armónica.

Paso 2: Usamos CR: vy = ux = 2x. Integramos respecto a y:

v(x,y) = ∫2xdy = 2xy+φ(x)

Paso 3: Aplicamos la segunda ecuación CR: vx = −uy ⇒ 2y + φ'(x) = −(−2y) = 2y ⇒ φ'(x) = 0 ⇒ φ(x) = C.

Así, v(x, y) = 2xy + C y la función analítica resultante es f(z) = (x2 − y2) + i(2xy + C) = z2 + iC.
