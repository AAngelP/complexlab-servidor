Teorema de De Moivre: Potencias y Raíces

Conocimiento crítico: Conversión obligatoria a coordenadas polares complejas: z = r(cos(θ) + i sen(θ))

1. Potenciación Compleja

Para cualquier número entero n, la fórmula simplifica el cálculo directo de potencias elevadas:

r ( cos θ + i sen θ ) n = r n cos ( n θ ) + i sen ( n θ )

Interpretación Geométrica: Elevar un complejo a la potencia n amplifica su distancia al origen de forma exponencial (rn) y rota su argumento multiplicando el ángulo original por n.

2. Raíces n-ésimas en el Plano Complejo

Todo número complejo tiene exactamente n raíces distintas. Se calculan variando el parámetro entero k desde 0 hasta n-1:

w k = r n cos θ + 2 k π n + i sen θ + 2 k π n

Interpretación Geométrica: Las n raíces se distribuyen simétricamente en el plano de Argand. Todas comparten el mismo módulo (rn), localizándose sobre una circunferencia y formando los vértices de un polígono regular de n lados centrado en el origen.
