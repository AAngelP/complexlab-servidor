Bases de Derivación Compleja

Conocimientos Previos
  • Números complejos en forma binomial: z = x + iy y su módulo |z| = √x2 + y2.
  • Concepto de vecindad abierta (disco) en el plano complejo ℂ.
  • Límites y derivadas ordinarias de funciones reales de una variable.

Sea f : D ⊆ ℂ → ℂ una función definida en una vecindad de z0. Decimos que f es derivable (o compleja-diferenciable) en z0 si existe el siguiente límite:

f'(z0) = limΔz→0 f(z0+Δz)−f(z0) Δz

A diferencia del cálculo real, donde Δx → 0 solo por izquierda o derecha, en ℂ el incremento Δz = Δx + iΔy puede acercarse a cero desde infinitas direcciones. Si el límite depende de la trayectoria elegida, la derivada no existe.

Reglas Elementales de Derivación
  • Constante y Potencia: d/dz [c] = 0  y  d/dz [zn] = n zn−1 para n ∈ ℤ.
  • Linealidad: [a f(z) + b g(z)]' = a f'(z) + b g'(z).
  • Producto: [f(z)g(z)]' = f'(z)g(z) + f(z)g'(z).
  • Cociente: [f(z) / g(z)]' = (f'(z)g(z) − f(z)g'(z)) / [g(z)]2, con g(z) ≠ 0.

Casos de Estudio Interactivos

Caso 1: Derivación por Definición de f(z) = z2 ▾

Aplicamos directamente el límite del cociente incremental en un punto arbitrario z ∈ ℂ:

f'(z) = limΔz→0 (z+Δz)2−z2 Δz = limΔz→0 z2+2zΔz+(Δz)2−z2 Δz = limΔz→0 (2z+Δz) = 2z

El resultado es independiente de cómo Δz → 0, por lo que f(z) = z2 es derivable en todo ℂ.

Caso 2: Función NO Derivable f(z) = z (Conjugado) ▾

Evaluamos el cociente incremental para f(z) = z usando Δz = Δx + iΔy:

z+Δz‾−z‾ Δz = Δz‾ Δz = Δx−iΔy Δx+iΔy

Trayectoria 1 (Eje Real, Δy = 0):

limΔx→0 ΔxΔx =1

Trayectoria 2 (Eje Imaginario, Δx = 0):

limΔy→0 −iΔyiΔy =−1

Como 1 ≠ −1, el límite no existe en ningún punto. f(z) = z no es derivable en ningún lugar de ℂ.

Caso 3: Derivación Racional con Reglas Elementales ▾

Calcular f'(z) para f(z) = (z3 − 2i) / (z + 1) con z ≠ −1:

f'(z) = (3z2)(z+1)−(z3−2i)(1) (z+1)2 = 2z3+3z2+2i (z+1)2
Caso 4: Derivabilidad Puntual en f(z) = |z|2 ▾

Analizamos f(z) = zz en z0 = 0:

f'(0) = limΔz→0 |0+Δz|2−0 Δz = limΔz→0 ΔzΔz‾ Δz = limΔz→0 Δz‾ = 0

Curiosamente, f(z) = |z|2 solo es derivable en z0 = 0 (donde f'(0) = 0), pero falla en cualquier otro punto z0 ≠ 0.
