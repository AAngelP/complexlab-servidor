Bases de Integración Compleja

Conocimientos Previos
  • Parametrización de curvas suaves en el plano: z(t) = x(t) + i y(t) para t ∈ [a, b].
  • Derivación compleja de curvas: z'(t) = x'(t) + i y'(t).
  • Integrales definidas de funciones reales de una variable.

Sea C una curva suave parametrizada por z(t) en el intervalo [a, b], y sea f(z) una función continua sobre C. La integral de contorno (o de línea) se define como:

∫C f(z)dz = ∫ab f(z(t)) ⋅ z'(t)dt
Propiedades y Desigualdad ML (Acotación)
  • Linealidad: ∫C [αf(z) + βg(z)] dz = α∫C f(z) dz + β∫C g(z) dz.
  • Inversión de sentido: ∫−C f(z) dz = −∫C f(z) dz.
  • Teorema Fundamental: Si f(z) tiene una antiderivada F(z) analítica en un dominio D que contiene a C (desde z1 hasta z2), entonces ∫C f(z) dz = F(z2) − F(z1).
  • Desigualdad ML: Si |f(z)| ≤ M en todo C y L es la longitud de arco de C, entonces:
|∫Cf(z)dz| ≤ M⋅L

Casos de Estudio Interactivos

Caso 1: Integral sobre Segmento Recto por Parametrización ▾

Evaluar ∫C z dz donde C es el segmento de recta desde z = 0 hasta z = 1 + i:

Paso 1: Parametrizamos: z(t) = t + it = (1 + i)t para t ∈. Entonces z'(t) = 1 + i y z(t) = (1 − i)t.

∫Cz‾dz = ∫01 (1−i)t⋅(1+i)dt = ∫01 2tdt = [t2]01 = 1
Caso 2: Integral sobre Circunferencia Unitaria (∫C 1/z dz) ▾

Calcular ∫C (1 / z) dz donde C es el círculo unitario |z| = 1 recorrido en sentido antihorario:

Parametrización: z(θ) = eiθ con θ ∈ [0, 2π]. Derivando: z'(θ) = i eiθ.

∮|z|=1 1zdz = ∫02π 1eiθ ⋅ ieiθdθ = ∫02π idθ = 2πi

Este es un resultado fundamental: a pesar de ser una curva cerrada, la integral no es cero porque 1/z tiene una singularidad en z = 0.

Caso 3: Uso de Antiderivada (Independencia de Trayectoria) ▾

Calcular ∫C (3z2 + 2z) dz a lo largo de cualquier curva suave desde z1 = 1 hasta z2 = 2 + i:

Como f(z) = 3z2 + 2z es entera, admite antiderivada global F(z) = z3 + z2:

∫12+i (3z2+2z)dz = F(2+i)−F(1) = [(2+i)3+(2+i)2] − (1+1) = [(2+11i)+(3+4i)]−2 = 3+15i
Caso 4: Acotación mediante Desigualdad ML ▾

Acotar el módulo de ∫C (1 / (z2 + 1)) dz donde C es el arco superior de |z| = 2 desde z = 2 hasta z = −2:

1. Longitud L: Semicircunferencia de radio R = 2 ⇒ L = πR = 2π.

2. Cota superior M: Por desigualdad triangular inversa, |z2 + 1| ≥ |z|2 − 1 = 22 − 1 = 3. Por tanto, |1 / (z2 + 1)| ≤ 1/3 = M.

|∫Cdzz2+1| ≤ M⋅L = 13⋅2π = 2π3
